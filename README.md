# NeuroOverlay — сайт для стрим-оверлея

Личный кабинет с входом через Telegram + персональная ссылка на оверлей
для OBS Studio и TikTok LIVE Studio. Бесплатный хостинг на Cloudflare
Workers, код — на GitHub, автодеплой при каждом изменении.

Все шаги ниже делаются в браузере — через сайты cloudflare.com и
github.com. Командная строка нигде не обязательна (если только вы сами
не захотите ей воспользоваться — короткая версия для этого в конце).

---

## Что где лежит

```
public/            — страницы сайта (вход, личный кабинет, оверлей, админка)
src/                — серверный код (Cloudflare Worker)
migrations/           — SQL для создания таблиц в базе данных
wrangler.jsonc          — конфигурация Cloudflare (какие сервисы подключены)
scripts/                  — вспомогательные команды (нужны только для командной строки)
```

## Шаг 1. Залить код в ваш GitHub-репозиторий

1. Зайдите в репозиторий `WZCasper/NeuroOverlay` на github.com.
2. Удалите старый `index.html`, если он там есть (это старая версия оверлея,
   больше не нужна — весь функционал сохранён в новой версии).
3. Нажмите **Add file → Upload files**.
4. Перетащите в окно браузера ВСЕ файлы и папки из архива, который я прислал
   (то есть содержимое этой самой папки — `public/`, `src/`, `migrations/`,
   `wrangler.jsonc`, `package.json` и так далее), сохраняя структуру папок.
   Современный GitHub поддерживает перетаскивание целых папок мышкой.
5. Внизу нажмите **Commit changes**.

Файлы `.dev.vars` и `.wrangler/` в архиве отсутствуют специально — это
локальные тестовые файлы, их не нужно загружать (они и так исключены
через `.gitignore`, на случай если вы позже будете обновлять код через git).

---

## Шаг 2. Завести аккаунт Cloudflare

1. Зайдите на **dash.cloudflare.com** → зарегистрируйтесь (бесплатно, карта
   не требуется).
2. В левом меню откройте **Workers & Pages**. Если это первый раз — Cloudflare
   попросит выбрать бесплатный поддомен вида `ваше-имя.workers.dev`. Введите
   любое удобное имя — это будет частью адреса вашего сайта.

---

## Шаг 3. Создать базу данных (D1)

1. В **Workers & Pages** откройте вкладку **D1 SQL Database** (иногда просто
   **D1** в левом меню) → **Create database**.
2. Назовите базу `neuroverlay` → **Create**.
3. На странице базы найдите **Database ID** (длинная строка вида
   `xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx`) — скопируйте её.
4. Перейдите в свой репозиторий на GitHub → откройте файл `wrangler.jsonc` →
   нажмите на иконку карандаша (Edit) → найдите строку:
   ```
   "database_id": "REPLACE_WITH_YOUR_D1_DATABASE_ID"
   ```
   и замените `REPLACE_WITH_YOUR_D1_DATABASE_ID` на скопированный ID
   (кавычки оставьте на месте) → **Commit changes**.
5. Вернитесь на страницу базы `neuroverlay` в Cloudflare → вкладка
   **Console** → откройте файл `migrations/0001_init.sql` в GitHub (или из
   присланного архива), скопируйте его содержимое целиком → вставьте в
   Console на Cloudflare → **Execute**. Это создаст таблицы для
   пользователей, сессий и настроек оверлея.
6. Точно так же выполните **все остальные файлы** из папки `migrations/`
   по порядку номеров (`0002_...`, `0003_...` и так далее, если появятся
   новые) — каждый добавляет что-то своё поверх предыдущего. Уже
   выполненный `0001` заново запускать не страшно — миграции написаны так,
   что повторный запуск ничего не портит.

---

## Шаг 4. Подключить репозиторий к Cloudflare (автодеплой)

1. В **Workers & Pages** нажмите **Create** → **Import a Git repository**.
2. Авторизуйтесь через GitHub, если попросит, и выберите репозиторий
   `WZCasper/NeuroOverlay`.
3. Cloudflare сам найдёт `wrangler.jsonc` в репозитории и предложит
   настройки по умолчанию — можно ничего не менять, нажать **Deploy**
   (Save and Deploy).
4. Дождитесь окончания сборки (обычно меньше минуты). После этого сайт уже
   доступен по адресу вида `https://neuroverlay.ваше-имя.workers.dev` —
   но пока не будет работать вход, это в следующем шаге.

С этого момента при каждом изменении файлов в GitHub-репозитории
(через веб-интерфейс или иначе) Cloudflare будет автоматически
пересобирать и обновлять сайт — ничего вручную нажимать не нужно.

---

## Шаг 5. Указать данные Telegram-бота

1. В **Workers & Pages** откройте ваш проект (`neuroverlay`) → **Settings**
   → **Variables and Secrets**.
2. Добавьте переменную:
   - **Name**: `TELEGRAM_BOT_USERNAME`
   - **Value**: имя вашего бота без `@`, например `my_overlay_bot`
   - Тип — обычная переменная (Text/Plaintext).
3. Добавьте ещё одну:
   - **Name**: `TELEGRAM_BOT_TOKEN`
   - **Value**: токен бота, который вам выдал @BotFather
   - Тип — **Secret** (шифруется, никто кроме сервера его не увидит).
4. Сохраните — Cloudflare предложит передеплоить проект, согласитесь.

---

## Шаг 6. Разрешить боту работать с вашим доменом

1. Откройте **@BotFather** в Telegram → `/mybots` → выберите вашего бота →
   **Bot Settings** → **Domain** → **Edit Domain**.
2. Введите домен вашего сайта БЕЗ `https://`, например:
   ```
   neuroverlay.ваше-имя.workers.dev
   ```
   (или ваш собственный домен, если подключите его позже — см. ниже).

Без этого шага кнопка «Войти через Telegram» не будет работать — Telegram
проверяет, что домен, с которого пришёл запрос на вход, совпадает с тем,
что указан в BotFather.

---

## Шаг 7. Проверить

1. Откройте `https://neuroverlay.ваше-имя.workers.dev` — должна открыться
   страница входа.
2. Войдите через Telegram — должно перекинуть в личный кабинет.
3. В личном кабинете вверху панели настроек будет ссылка вида
   `.../overlay/<токен>` — именно её вставляете в OBS (Источник → Browser)
   или в TikTok LIVE Studio (Add Source → Link).
4. Что-нибудь поменяйте в панели — изменение должно появиться в источнике
   OBS/TikTok без перезагрузки, в течение секунды.

## Как получить права администратора (посмотреть список пользователей)

Админ-панель (`/admin`) только показывает список зарегистрированных —
управлять там нечем, сайт бесплатный. Чтобы открыть её для себя:

1. Сначала войдите на сайт хотя бы один раз через Telegram (обычным
   способом, как в Шаге 7) — так ваш аккаунт появится в базе.
2. В Cloudflare откройте базу `neuroverlay` → вкладка **Console**.
3. Выполните (замените `ваш_username` на свой Telegram username без `@`,
   либо используйте `telegram_id = 123456789`, если username не задан):
   ```sql
   UPDATE users SET is_admin = 1 WHERE username = 'ваш_username';
   ```
4. Обновите страницу `/dashboard` — снизу появится ссылка «⚙ Админ-панель».

## Свой домен вместо `*.workers.dev`

Если у вас есть домен, подключённый к Cloudflare: откройте проект → вкладка
**Settings → Domains & Routes** → **Add** → укажите домен/поддомен. После
этого не забудьте обновить домен в BotFather (Шаг 6) на новый.

## Если вы всё же дружите с командной строкой

Всё то же самое можно сделать через `wrangler` (Cloudflare CLI), если
установлен Node.js:

```bash
npm install
npx wrangler login
npx wrangler d1 create neuroverlay        # скопируйте выданный database_id в wrangler.jsonc
npx wrangler d1 execute neuroverlay --file=migrations/0001_init.sql --remote
npx wrangler secret put TELEGRAM_BOT_TOKEN
npx wrangler secret put TELEGRAM_BOT_USERNAME
npx wrangler deploy
```

Для локальной разработки (без реального Cloudflare-аккаунта):

```bash
npm install
cp .dev.vars.example .dev.vars     # впишите туда тестовые значения
npx wrangler d1 execute neuroverlay --file=migrations/0001_init.sql --local
npm run dev                          # сайт на http://localhost:8787
npm run smoke-test                     # прогнать проверочные тесты
```

## Как это устроено (коротко)

- **Cloudflare Workers** — один и тот же сервис отдаёт и статичные
  страницы, и обрабатывает вход/API.
- **D1** — база данных (аккаунты, привязка к Telegram, сохранённые
  настройки оверлея).
- **Durable Objects** — держит открытое соединение с каждой открытой
  страницей оверлея, чтобы изменения в личном кабинете появлялись в
  OBS/TikTok мгновенно, без обновления страницы.
- Вход проверяется по-настоящему: подпись от Telegram сверяется на
  сервере (секретным токеном бота, который никогда не попадает в
  браузер) — это заменяет старую систему с лицензионным ключом,
  которая была видна и подделываема прямо в браузере.
- Ссылка на оверлей (`/overlay/<токен>`) — работает без входа, специально
  для OBS/TikTok, но токен длинный и случайный: относитесь к нему как к
  паролю, никому не показывайте. Если ссылка всё же "утекла" — в личном
  кабинете есть кнопка "Обновить ссылку", старая сразу перестанет работать.
- **Профили** — у одного аккаунта может быть несколько независимых
  профилей оверлея (например, «16:9» и «9:16»), каждый со своей раскладкой
  виджетов и своей ссылкой. Переключаются выпадающим списком вверху панели
  настроек.
